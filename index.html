About Me

The developer behind the code

Who I am

I'm Rania Gabal, a Frontend Developer who enjoys turning ideas into interfaces that feel effortless to use. I care about the details other people skip: the transition that's 100ms too slow, the button that isn't quite reachable on mobile, the state that's missing a loading indicator.

My journey

I started with HTML and CSS, curious about how websites were put together, then moved into JavaScript to make them interactive. Along the way I picked up React.js for building component-driven apps, and Tailwind CSS for styling quickly without losing control over design. Every project has pushed me to write cleaner, more reusable code.

Where I'm headed

My goal is to keep growing as a frontend engineer by building scalable web applications with React and Next.js, improving my problem-solving skills, and contributing to products that deliver great user experiences. I'm excited to learn modern frontend technologies and collaborate with experienced teams while continuously improving my craft.
