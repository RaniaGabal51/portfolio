A modern, responsive personal portfolio showcasing my frontend development projects, technical skills, and professional journey. Built with HTML, CSS, JavaScript, and Tailwind CSS, featuring a clean UI, smooth animations, and an interactive user experience.

## Features

- Responsive design for all screen sizes
- Modern glassmorphism UI
- Dark / Light mode with localStorage
- Smooth scrolling and scroll animations
- Interactive typing effect
- Animated skills section
- Project filtering and search
- Project details modal
- Contact form with EmailJS integration
- Downloadable resume
- Optimized for performance and accessibility
